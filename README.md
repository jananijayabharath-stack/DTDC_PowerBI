# DTDC_PowerBI
DTDC Logistics Performance Dashboard (Power BI)

This project showcases an interactive Power BI dashboard built for DTDC to support executive‑level decision‑making. The dashboard visualizes key logistics metrics such as delivery volumes, revenue by city, customer payment behavior, and shipment trends, with a focus on usability for regional and operations managers.

Key Features: 

📊 Donut Chart for Payment Modes

* Created using a DAX‑derived column to classify payment methods.
* Consignment count used as the value to define slice size.
* Fully customizable through Power BI’s native donut visual (colors, labels, tooltips).

⚙️ KPI Parameter (Select Metric)

* Built using Power BI’s New Parameter wizard.
* Measures included: Total Revenue, Total Deliveries, Total Delivery Weight.
* Automatically generates a slicer and supporting logic for seamless KPI switching.

🏙️ City Revenue Ranking

* Implemented using Top N visual‑level filters.
* Displays top‑performing cities based on total revenue.
* Ideal for dashboards requiring clarity and fast performance.

📈 Line & Area Charts

* Standard Power BI visuals used to show trends over time.
* Legend assigned through the Legend field for category‑based comparison.

🔗 Dashboard Interactions

* Controlled using Edit Interactions to define how visuals filter or highlight each other.
* Clicking a state or city updates the entire dashboard context instantly.

🎨 Theme & Color Customization

* Customized using Power BI’s formatting pane.
* Blue‑based theme applied across visuals for consistency and readability.

📝 Summary

Power BI enabled fast, flexible, and highly interactive dashboard development for DTDC. Automated parameter creation, intuitive filtering, and rich formatting options made it efficient to build a user‑friendly performance overview tailored for leadership insights.
